# software-install-layout

一套用于 Windows 的软件安装目录规范，供 AI agent 在安装、摆放、迁移软件时遵循。

本包为**通用版**：根路径不预定义，由 `root.conf` 指定；四件套布局（`body` / `mods` / `loads` / `back`），`tools` 分独立型 `standalone` 与依赖型 `dependent`；宿主分全局宿主与分类宿主（启动器），插件与启动器下的游戏作为宿主 `mods` 组件平铺；需先启动宿主的应用增设备注与宿主快捷方式；原包半永久保留，卸载走墓碑并切断索引（结构 / 宿主 / 登记三类），残留清零才算卸载完成。

## 安装

1. 解压本包，得到 `software-install-layout` 文件夹。
2. 将整个文件夹放入以下目录（不存在则自行创建）：

```
C:\Users\<用户名>\.agents\skills\
```

3. **定义根路径**：打开 `root.conf`，把 `status` 改为 `DEFINED`，把 `apps_root` 填成这台机器上 apps 根目录的绝对路径（如 `E:\apps`）。根目录不必已存在，但盘符必须存在。

4. 重启 agent 或新开一个会话。技能列表中出现 `software-install-layout` 即为安装成功。

## 使用

对 agent 说：

```
按照安装规范安装 <软件名>
```

agent 会加载本技能，先读取 `SPEC.md` 与 `root.conf`，确认根路径后按规范规划落点并报告方案。

确认方案无误后，再下达执行指令，agent 才会动手建目录、放置文件。

在新机器上首次使用时，可先让 agent 做一次首装自检（`SPEC.md` 13.2）：只盘点、报告，不修改。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `SKILL.md` | 技能入口：触发条件、硬约束、速记 |
| `SPEC.md` | 规范全文：根路径定义、分类与类型判定、四件套、命名规则、日志与备份滚动、备份分层、重定向、索引定义与切断、安装与卸载流程 |
| `README.md` | 本文件：安装、使用、版本说明 |
| `root.conf` | 唯一的本机参数：根路径定义状态与实际路径 |

`SKILL.md` 与 `SPEC.md` 冲突时，以 `SPEC.md` 为准。

## 边界

- 本包只管目录结构，不管软件怎么装、装什么版本。
- 不写凭据、密钥、用户名、机器名。
- `root.conf` 每台机器各自维护，复制整个技能目录到新机器后要重新定义。
- 根路径确认前，agent 不应创建任何目录。
